# 监控告警

## 监控功能概览

| 功能 | 说明 |
|------|------|
| 监控任务 | URL 监控（状态码规则/内容匹配/SSRF 防护） + 资源监控（网页空间/数据库空间/流量阈值），每用户最多 5 个 |
| 检测日志 | 监控检测历史记录，查看状态码/响应时间/错误信息 |
| 通知日志 | 到期提醒、流量超额、监控告警，支持筛选/搜索/分页/全部已读 |

## URL 监控

- 状态码规则：按期望的 HTTP 状态码判断站点是否正常
- 内容匹配：检测页面响应内容是否包含/不包含指定关键词
- **SSRF 防护**：内置防护，避免监控请求被用于内网探测
- 默认检测间隔 60 秒

## 资源监控

- 监控网页空间 / 数据库空间 / 流量使用率，超过阈值触发告警
- 资源监控固定 180 秒检测一次
- 到期提醒（7/3/1/0 天）与流量超额（>=80%）自动写入通知日志

## 监控任务如何生效？

1. 每个用户最多 5 个监控任务
2. URL 监控默认间隔 60 秒，资源监控固定 180 秒
3. 需在宝塔计划任务中配置每分钟访问 `jk_monitor.php?my=API密钥`
4. 通知日志会自动记录到期提醒（7/3/1/0 天）和流量超额（>=80%）

## 相关文件

- `user/monitor.php` —— 监控任务管理页
- `user/monitor_log.php` —— 监控检测日志页
- `user/notice.php` —— 通知日志页（到期/流量/监控告警）
- `jk_monitor.php` —— 监控计划任务执行脚本（URL 检测/资源阈值/到期提醒）
- `MPHX/monitor.function.php` —— 监控函数库（自动建表/URL 检测/资源百分比/SSRF 防护/邮件通知）
