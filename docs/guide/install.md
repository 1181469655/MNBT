# 安装部署

## 环境要求

| 依赖 | 版本要求 |
|------|---------|
| PHP | 面板自身运行环境 **建议 ≥ 8.2.35 / 8.3.36 / 8.4.27 / 8.5.12**（推荐 8.4.27+；安装向导检测后要求显式确认风险，不做版本拦截） |
| MySQL | 5.6 ~ 8.x（含 MySQL 8.0+） |
| Web 服务器 | Nginx / Apache |
| 宝塔面板 | Linux 版 / Windows 版 |
| PHP 扩展 | curl、mysqli、json、mbstring |
| Composer | 可选（仅用于 PHPMailer 安装） |

> 已修复 `each()`、`count($string)`、`get_magic_quotes_gpc()` 等 PHP 8 废弃语法；所有 SQL 已迁移至参数化查询。面板代码本身仍兼容 PHP 7.4 ~ 8.4 语法，上面的版本建议是**安全要求**而非语法要求，安装向导只做提示与风险确认，不按版本拒绝安装。
>
> ⚠️ **安全说明（php2shell）**：PHP 官方 2026 年发布的 CVE-2026-109618 / CVE-2026-109619（CVSS 9.2）允许未认证攻击者用构造的 multipart POST 请求远程执行代码，**只有 8.2.35 / 8.3.36 / 8.4.27 / 8.5.12 及更高版本包含补丁**。PHP 7.4 / 8.0 / 8.1 已停止上游维护，官方不会再出补丁，装在这些版本上的面板属于永久未修补状态，所以安装向导会把 PHP 项标成警示态，并要求勾选「我已知悉当前 PHP 未修复 php2shell，风险自负，继续安装」后才让你提交——**面板不以 PHP 版本为由拒绝安装，是否继续使用旧版本由运维自己决定**。同一批 2026 年修复还包含 OpenSSL 主机名校验缺陷（CVE-2026-91769 / CVE-2026-91767）、跨源重定向凭证泄漏（CVE-2026-91766）与 CVE-2026-93682，升级到这四个补丁版本（8.2.35 / 8.3.36 / 8.4.27 / 8.5.12，5 月与 9 月的常规安全版本不覆盖 php2shell）可一并处理。
>
> **暂时无法升级的服务器的临时缓解**：在面板自身的 `php.ini` 中设置 `session.upload_progress.enabled = 0`（并重启 PHP-FPM），只作为过渡措施，请尽快升级到修复版本；租户站点侧的 `bash.conf.php` PHP-FPM 池模板也已写入 `php_admin_value[session.upload_progress.enabled] = 0`（`php_admin_value` 让租户无法用 `.user.ini` 或 `ini_set` 覆盖），但**该模板在当前版本没有下发通道**（旧「修复配置」入口随 classic 后台一起移除，租户池实际由宝塔节点在建站/切版本时按节点默认生成），所以要真正生效仍需在节点侧手工处理，具体命令见[安全说明](/guide/security)的「缓解」一节。同批次 CVE、出站 TLS 校验开关与升级动作清单见[安全说明](/guide/security)。
>
> **MySQL 8 用户**：系统在安装与运行时会话级清空 `sql_mode`，兼容 MySQL 8 默认严格模式；MySQL 8 默认认证插件为 `caching_sha2_password`，需 PHP 使用 mysqlnd 驱动（PHP 7.4+ 默认自带）方可连接，若 PHP 编译时使用 libmysqlclient 可能报 "Authentication plugin not supported"。

## 安装部署

### 1. 准备环境

建议服务器已安装 **已修复 php2shell 的 PHP**（8.2.35 / 8.3.36 / 8.4.27 / 8.5.12 及以上，推荐 8.4.27+）+ MySQL，并已安装宝塔面板；仍是旧版本可以继续安装，向导会要求你勾选风险确认。

### 2. 部署代码

```bash
# 将安装包上传至网站目录并解压
# 设置网站运行目录为 /
# 配置伪静态规则（如使用 ThinkPHP 风格 URL）
```

### 3. 运行安装向导

访问 `http://你的域名/install`，按向导提示完成：

1. 欢迎 / 许可协议
2. 环境检测（PHP 是否已修复 php2shell：8.2.35 / 8.3.36 / 8.4.27 / 8.5.12 及以上、curl 等；PHP 未修复时该项显示警示并要求勾选风险确认，勾选后可继续，不勾选则无法提交）
3. 数据库配置（填写 MySQL 连接信息）
4. **站点与管理员**（控制面板名称、站长 QQ、公告、管理员账号密码）
5. 初始化数据库（自动导入表结构，或重装模式）
6. 完成安装（完成页会显示你设置的管理员账号）

### 4. 登录管理

- 管理后台：`http://你的域名/admin`
- 账号/密码：安装向导中设置的管理员信息（不再固定 `admin/123456`）
- ⚠️ **请妥善保存密码；安装后建议删除 `install` 目录**

### 5. 对接宝塔面板

1. 登录管理后台 → 宝塔管理 → 添加宝塔
2. 填写宝塔面板地址、端口、API 密钥
3. 宝塔面板中需开启 API 接口：面板设置 → API 接口 → 开启
4. 设置默认建站目录（Linux：`/www/wwwroot`，Windows：`D:/wwwroot`）

### 6. 配置计划任务（监控系统）

在宝塔面板 → 计划任务中添加：

| 任务类型 | 执行周期 | 执行命令 |
|---------|---------|---------|
| 访问命令 | 每分钟 | `php -r '$t=time();echo file_get_contents("http://你的域名/jk_monitor.php?t=".$t."&sign=".hash_hmac("sha256","jk_monitor|".$t,"API密钥"));'`（宝塔计划任务-Shell 脚本；兼容旧 `?my=`，已弃用） |

API 密钥可在管理后台 → 系统设置 → API 接口中查看。

### 7. 安装节点插件（可选）

如需使用分布式节点管理 + 违禁词扫描功能：

```bash
# 1. 在管理后台 → 节点管理 → 添加节点
# 2. 将 plugins/mnbt_connector/ 部署到宝塔服务器
# 3. 复制生成的 config.json 配置
# 4. 重启插件服务
systemctl restart mnbt-connector.service
```

## 快速开始

最简部署流程：

```bash
# 1. 上传代码
cd /www/wwwroot/your-domain
# 解压安装包

# 2. 设置权限
chmod -R 755 .
chown -R www:www .

# 3. 访问安装向导
# 浏览器打开 http://your-domain/install

# 4. 登录后台，修改默认密码
# 浏览器打开 http://your-domain/admin

# 5. 添加第一台宝塔服务器
# 后台 → 宝塔管理 → 添加宝塔

# 6. 配置默认建站目录和监控任务
# 后台 → 系统设置 → 基础设置
# 宝塔面板 → 计划任务 → 添加监控任务
```
